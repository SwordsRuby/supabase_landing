# Supabase Storage Landing Page

Этот проект представляет собой статический лендинг для сервиса хранения данных Supabase Storage. Сайт демонстрирует возможности продукта, интерфейс управления файлами и интеграции с системой аутентификации.

## 📋 Содержание

- [Особенности](#особенности)
- [Технологии](#технологии)
- [Функциональность](#функциональность)

## 🚀 Особенности

- **Темная/светлая тема** — переключение между темами с сохранением состояния
- **Интерактивные элементы** — выпадающие меню, FAQ-аккордеон, слайдер
- **Модальные окна** — формы авторизации и регистрации
- **Динамический контент** — переключение вкладок панели управления
- **Слайдер** — автоматическая смена изображений в баннере

## 💻 Технологии

- **HTML5** — семантическая структура страницы
- **CSS3** — стилизация, анимации, переменные для тем
- **JavaScript (Vanilla)** — интерактивность без сторонних библиотек
- **Google Fonts** — шрифт Roboto

## ⚙️ Функциональность

### Навигация
- Выпадающие меню "Product" и "Developers"
- Переходы между разделами
- Кнопки авторизации и регистрации

### Интерактивные компоненты
1. **Слайдер** — автоматическая смена изображений каждые 5 секунд
2. **Панель управления** — переключение между вкладками с изменением изображения и контента
3. **FAQ-аккордеон** — раскрывающиеся блоки с ответами
4. **Темы** — переключение между светлой и темной темой

### Модальные окна
- **Авторизация** — форма входа с валидацией полей
- **Регистрация** — форма создания аккаунта с проверкой пароля
